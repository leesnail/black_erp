# BLACK ERP 需求文档

> 版本：v1.0（基于初版需求整理）
> 日期：2026-10-20
> 状态：需求基线草案，待确认项见文末

---

## 1. 系统概述

面向电商团队（以抖店为主）的内部协同管理系统，打通**客服、采购、运营、财务、老板**五个岗位的数据，实现：

- 成本自动核算、利润自动计算
- 权限分级管理（按岗位控制模块可见范围）
- 全部业务数据集中在一个系统内，不分散

## 2. 用户角色与权限

| 角色 | 可见模块 | 权限级别 |
|------|----------|----------|
| 老板 | 全部模块 | 最高权限（只读/全局查看 + 全部操作） |
| 管理员 | 全部模块 + 账号管理、权限分配 | 管理员 |
| 客服 | 客服模块 + 供应商信息表 | 员工 |
| 采购 | 成本报价模块 | 员工 |
| 运营 | 运营模块 + 成本报价模块（只读） | 员工 |
| 财务 | 财务模块 + 成本模块（只读） | 员工 |

**权限规则：**

- FR-Auth-01：每个员工使用独立账号登录。
- FR-Auth-02：管理员可为账号分配模块可见范围（可覆盖上表默认值）。
- FR-Auth-03：无权限模块对用户不可见（非仅隐藏入口），且接口层拒绝访问。
- FR-Auth-04：只读权限 = 可查询、可导出，不可新增/修改/删除。

## 3. 功能需求

### 3.1 客服模块（FR-CS）

| 编号 | 功能 | 需求说明 |
|------|------|----------|
| FR-CS-01 | 售后登记 | 记录客户售后问题、处理结果；支持按订单/客户/时间查询 |
| FR-CS-02 | 供应商对接登记 | 登记供应商信息：对接微信群、供应产品、对接人/联系方式 |
| FR-CS-03 | 发票登记 | 记录发票信息（发票号、金额、供应商、开票日期等） |
| FR-CS-04 | 发票回传 | 上传发票照片/文件作为凭证 |
| FR-CS-05 | 发票提醒 | 系统**每 8 天**自动提醒客服处理发票数据（提醒任务可配置、可记录已读） |

### 3.2 采购模块 — 成本报价表（FR-PO）

| 编号 | 功能 | 需求说明 |
|------|------|----------|
| FR-PO-01 | 报价录入 | 采购录入供应商报价，支持**文字录入**与**图片识别**（拍照/截图自动提取报价信息，OCR） |
| FR-PO-02 | 统一成本表 | 全公司统一一张成本表，字段：产品名称、规格编码、各规格报价、对应供应商、供应商对接方式、产品图片 |
| FR-PO-03 | 规格编码 | 每个规格有唯一编码，作为关联其他模块的关键字段（唯一性校验、不可重复） |
| FR-PO-04 | 供应商信息 | 记录供应商名称、对接群、联系人、联系方式；支持多供应商 |

### 3.3 运营模块（FR-OP）

| 编号 | 功能 | 需求说明 |
|------|------|----------|
| FR-OP-01 | 产品登记 | 按店铺登记：店铺名称、商品标题关键字、链接 ID、**规格编码（从成本表选择，不可手填）**、对应规格售价 |
| FR-OP-02 | 成本查看 | 只读查看成本报价表，通过**规格编码**关联 |
| FR-OP-03 | ROI 计算 | 输入投放花费、成交金额，自动计算 ROI = 成交金额 / 投放花费 |

### 3.4 财务模块（FR-FIN）

| 编号 | 功能 | 需求说明 |
|------|------|----------|
| FR-FIN-01 | 订单回传 | 上传店铺**订单导出表**与**待结算订单表**；格式不限（Excel/CSV 等），系统自动识别列 |
| FR-FIN-02 | 一键计算 | 点击"确认计算"，系统联动三方数据：采购成本报价 + 运营登记的售价/规格 + 订单数据 |
| FR-FIN-03 | 自动核算 | 自动计算并展示：订单成本、售价、毛利、利润率 |
| FR-FIN-04 | 日报 | 每日自动生成经营日报，含各店铺订单量、成本、利润 |

## 4. 核心数据联动逻辑

> 已确认采用**方案 A：规格编码为全系统主键**。标题关键字 + 规格售价仅作为订单侧反查到编码的匹配手段，匹配结果必须落到规格编码。

```
采购录入报价 → 生成规格编码（成本表主键）
        ↓
运营登记产品（店铺 + 标题关键字 + 规格编码[必选] + 规格售价 + 链接 ID）
        ↓
财务回传订单（按 标题关键字 + 规格售价 反查 → 落到规格编码）
        ↓
系统自动计算：
  成本 =（拿货价 + 地区附加）× 数量
  利润 = 实收 − 成本
        ↓
自动汇总到经营日报 / 月度对账表
```

**联动关键字段：**

1. **规格编码**：全系统关联主键，采购建成本表时生成，唯一且不可重复；运营登记必选。
2. **商品标题关键字 + 规格售价**：仅用于订单侧反查（订单数据中无编码），模糊匹配后落到编码。

**匹配规则补充需求（FR-LINK-01）：**

- 一条订单命中多条候选记录时，需按"规格售价完全一致优先 → 关键字命中长度最长优先"排序，并给出人工确认入口。
- 匹配不上的订单进入"待人工匹配"列表，可手动指定规格编码后重算（人工指定的编码-标题对应关系可沉淀为匹配规则，减少下次人工）。
- 同一店铺允许多个链接 ID 对应同一规格编码。

### 4.3 订单成本核算细则（FR-CALC，月度对账场景）

**输入数据**

| 来源 | 说明 |
|------|------|
| 订单明细 CSV（抖店订单导出） | 文件名**前 2 个字 = 店铺名**（如 `誉恒8月份.csv` → 店铺"誉恒"），据此归属店铺 |
| 成本表 XLSX | **固定模板**（已确认），列名固定不可改：店铺名称、产品标题名、规格售价、拿货价；建议增列规格编码以对齐方案 A 主键 |

**CSV 关键字段**

- `选购商品`：格式为 `产品标题-规格`（如 `…中秋节盒装-【普通装】香葱椒盐月饼60g*10枚`），按**最后一个 `-`** 拆分为标题与规格。
- `快递信息`：为空或占位符 `-` 表示**无物流**，该订单**不计算成本**；有值才计算。
- `售后状态`、`订单状态`：用于过滤口径（见计算步骤 2）。
- `省`：用于偏远地区运费加价。
- `商品数量`、`商品金额`、`商家收入金额`：用于成本与利润核算。

**计算步骤**

1. 读取 CSV，按文件名前 2 字识别店铺。
2. 过滤订单：
   - `快递信息` 为空/`-` 的行跳过，不计成本；
   - **按 `售后状态` 过滤**：已发生售后/退款的订单**仍计入采购成本**（货已发出、成本已发生），"售后单数"仅作汇总表展示列，不参与成本扣减。
3. 按 **店铺名 + 产品标题名 + 规格售价** 在成本表 XLSX 中匹配，取**拿货价**。
4. 按收货省份追加偏远地区附加成本（**按件计**，每件商品均加）：
   - 海南、青海、内蒙古、宁夏、甘肃：**+4 元/件**
   - 新疆、西藏：**+20 元/件**
5. 单件成本 = 拿货价 + 地区附加；行成本 =（拿货价 + 地区附加）× 商品数量。
6. 汇总输出。

**输出要求**

1. **成本明细表**（每个店铺/每个 CSV 一张）：逐条列出订单号、选购商品、店铺、拿货价、地区附加（元/件）、商品数量、该商品成本。
2. **成本汇总表**（系统自动计算，**商家实收 = 该店铺订单 `商家收入金额` 之和**，财务无需手填）：

   | 店铺名称 | 商家实收（=Σ商家收入金额） | 发货单数 | 售后单数（仅展示） | 采购成本 | 利润 |
   |---|---|---|---|---|---|

   其中 **利润 = 商家实收 − 采购成本**。
3. **未匹配清单**：`快递信息` 有值但在成本表中匹配不到的选购商品，必须单独列出并标注，不得静默丢弃。

**匹配与异常规则**

- 多条候选命中时：规格售价完全一致优先 → 标题关键字命中长度最长优先。
- 匹配不到的有物流订单进入未匹配清单，补录成本表后可一键重算。
- 金额计算保留 2 位小数，四舍五入。

## 5. 非功能需求（NFR）

| 编号 | 类别 | 要求 |
|------|------|------|
| NFR-01 | 集中化 | 全部数据存储在同一系统内，不分散到多个工具 |
| NFR-02 | 多租户式扩展 | 支持多店铺、多供应商并行使用 |
| NFR-03 | 易用性 | 操作界面简单，员工可快速上手；关键操作 ≤ 3 步完成 |
| NFR-04 | 提醒任务 | 发票提醒每 8 天自动推送，任务失败可重试并记录日志 |
| NFR-05 | 数据导入 | 成本表 XLSX 采用**固定模板**（列名固定，导入时校验表头，不符则报错并提示）；订单 CSV 按表头识别关键列 |
| NFR-06 | 数据安全 | 员工账号独立、密码策略、操作日志留痕；关键数据（成本、利润）仅授权角色可见 |
| NFR-07 | 性能 | 单次"一键计算"支持 ≥ 1 万条订单，响应时间 ≤ 30 秒 |
| NFR-08 | 可追溯 | 每次成本/利润计算保留计算批次，可查看输入数据版本，支持重算 |

## 6. 核心数据实体（初步）

- **供应商**：名称、对接群、联系人、联系方式、供应产品
- **产品/规格**：产品名称、规格编码（唯一）、各规格报价、供应商、产品图片
- **店铺产品登记**：店铺名称、商品标题关键字、链接 ID、规格编码、规格售价
- **订单**：来源表、订单号、商品标题、规格、数量、实际售价、结算状态
- **发票**：发票信息、回传附件、提醒状态
- **售后记录**：问题描述、处理结果、关联客户/订单
- **计算批次**：计算时间、输入数据、输出结果（成本/毛利/利润率）
