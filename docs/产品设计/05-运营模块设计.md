# 05 运营模块设计

> 对应需求：FR-OP-01 产品登记（规格编码必选）、FR-OP-02 成本只读、FR-OP-03 ROI 计算
> 使用角色：运营（写）

## 1. 店铺产品登记（FR-OP-01）

**列表页**

```
┌ 店铺产品登记   店铺: [誉恒▾]   [+ 新增登记]
│ 标题关键字 | 链接ID | 规格编码 | 规格 | 售价 | 状态 | 操作
│ 葱香椒盐月饼盒装 | 3835688988… | SP000123 | 60g×10枚 | 69.90 | 启用 | 编辑
└
```

**新增登记（对话框，≤3 步，NFR-03）**

```
① 标题关键字 [香葱椒盐月饼________]   链接ID [________]
② 选择规格:  [🔍 搜索成本表…]
   ┌─────────────────────────────┐
   │ SP000123 60g×10枚 拿货价32.00 │  ← 编码只读展示，不可手输
   │ SP000124 60g×15枚 拿货价45.00 │
   └─────────────────────────────┘
③ 规格售价 *[69.90]        [取消] [保存]
```

**规则**

- 规格编码只能从成本表选择器选入（FR-Auth/需求确认：不可手填）
- 选择器搜索：按编码/产品名/规格名过滤；仅显示"启用"状态 Spec
- 售价用于财务侧订单反查，保存前提示"该规格已有登记售价 69.90，新售价将并存，靠订单金额区分"
- 同店铺 (标题关键字, 售价) 重复 → 阻断保存
- 编辑时若该规格已被历史批次引用，提示"影响历史批次重算结果"（批次本身不可变，仅新批次受影响）

## 2. 成本只读（FR-OP-02）

- 复用采购"规格成本表"页面组件，按权限去掉新增/编辑/导入按钮
- 可看拿货价、供应商对接方式（对接群/联系人）；可搜索、可导出
- 不可看价格历史中的录入人绩效类信息（首版无此字段，仅约束）

## 3. ROI 计算（FR-OP-03）

**字段**：店铺、周期（日/月）、投放花费、成交金额 → 自动算 ROI = 成交金额 / 投放花费

```
┌ ROI 计算  店铺[▾] 周期[2026-08▾]
│ 投放花费 [20000]  成交金额 [60000]
│ ROI = 3.00
│ [保存记录]
│ 历史: 月份 | 花费 | 成交 | ROI | 保存人
└
```

- 口径默认值（Q6 遗留，不答按此）：成交金额取商家收入金额、按月
- 花费首版手填；二期对接千川/电商罗盘
- 保存为运营自留记录，不进入财务成本核算
