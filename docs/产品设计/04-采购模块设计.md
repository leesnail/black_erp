# 04 采购模块设计

> 对应需求：FR-PO-01 报价录入（含 OCR）、FR-PO-02 统一成本表、FR-PO-03 规格编码、FR-PO-04 供应商信息、NFR-05 XLSX 固定模板导入
> 使用角色：采购（写）｜运营/财务（读）｜老板（读）

## 1. 供应商管理（FR-PO-04）

**字段**：名称、对接微信群、联系人、联系方式、供应产品、备注。

- 列表页：搜索/筛选；删除为**停用**（已被报价引用不可物理删除）
- 与客服"供应商对接"共用实体，字段权限见 03 文档

## 2. 规格成本表（FR-PO-02 / FR-PO-03）⭐ 主数据核心

**列表页**

```
┌ 规格成本表          [新增规格] [导入XLSX] [下载模板] [导出]
│ 搜索: 编码/产品名/供应商        筛选: 供应商▾ 状态▾
│ ☑ 编码     产品名称   规格    拿货价   供应商   更新时间  操作
│ SP000123  香葱椒盐月饼 60g×10枚  32.00  誉恒源   08-12   编辑 历史
│ SP000124  香葱椒盐月饼 60g×15枚  45.00  誉恒源   08-12   编辑 历史
└
```

**新增/编辑抽屉**

```
产品名称 *  [________]        规格名 * [________]
默认供应商 * [选择 ▾]          本版拿货价 * [____] 元
产品图片    [上传]             备注 [________]
              [取消]  [保存并生成编码]
```

**交互规则**

- 保存成功自动生成编码（SP+6 位序列），toast 提示"编码 SP000125 已生成"；编码不可编辑
- 编辑价格 = 新增一条 CostPrice 历史，不覆盖旧值；"历史"入口查看价格变动时间线
- 编辑其他字段（名称/图片）直接更新 Spec
- 状态停用后：运营登记选择器不可选；历史登记与计算不受影响

## 3. 报价录入 + OCR（FR-PO-01）

- 主路径：成本表抽屉直接录价（见上）
- OCR 入口：抽屉顶部 **[拍照/截图识别]** → 上传图片 → 识别预填 产品名/规格/价格 → **人工确认后保存**（Q4 默认：识别结果必须人工确认）
- OCR 二期说明：首版可先隐藏入口，接口预留 `ocr.extract(image) -> {product_name, spec_name, price, confidence}`
- 低置信度（<0.8）字段标黄提醒重点核对

## 4. XLSX 固定模板导入（NFR-05）

```
上传成本表（固定模板）
① [拖入 .xlsx]   ② 表头校验: ✓ 店铺名称 ✓ 产品标题名 ✓ 规格售价 ✓ 拿货价
   预检: 共 86 行 · 新增 80 · 价格更新 5 · 异常 1（第 17 行规格售价为空）
                        [取消]  [确认导入]
```

**规则**

- 表头缺失 → 整表拒绝，列出缺失列名
- 行级异常（空值/非数字）→ 跳过该行并计入异常清单，可下载异常行文件
- 导入 upsert 逻辑：按"产品标题名+规格售价"命中已有 Spec → 更新价格历史；未命中 → 新建 Spec 并生成编码
- 建议模板增列"规格编码"：有编码列时优先按编码对齐（对齐方案 A 主键）
