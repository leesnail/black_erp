# 09 系统管理与非功能设计

> 对应需求：NFR-01~08、FR-Auth 管理端
> 使用角色：管理员（系统管理）｜全员（受非功能约束）

## 1. 系统管理功能

### 1.1 账号管理

- 增删改、启用/停用、重置密码、重置后强制首登改密
- 字段：姓名、账号、角色、状态、最后登录时间

### 1.2 角色与权限

- 默认预置需求文档权限表（老板/管理员/客服/采购/运营/财务六角色）
- 管理员可为**单个账号**覆盖模块可见范围（个人覆盖 > 角色默认，覆盖项在列表高亮）
- 模块粒度：客服工作台 / 成本报价 / 运营管理 / 财务核算 / 经营驾驶舱 / 系统管理
- 权限变更立即生效（会话内二次加载权限）

### 1.3 附加成本规则

- 列表：规则名、省份多选、金额（元/件）、启停
- 预置不可删、可改金额与省份；管理员可新增规则
- 示例：

| 规则 | 省份 | 金额 | 状态 |
|------|------|------|------|
| 西北西南附加 | 海南 青海 内蒙古 宁夏 甘肃 | 4.00 | 启用 |
| 远西部附加 | 新疆 西藏 | 20.00 | 启用 |

- 修改历史写入操作日志；**仅影响之后的计算与重算**，历史批次结果不变

### 1.4 操作日志（AuditLog）

- 记录：人、时间、IP、模块、动作（create/update/delete/export/calculate）、对象 id、变更摘要
- 关键动作必记：权限变更、价格修改、人工匹配/忽略、批次计算与重算、规则修改
- 日志只读、不可删；按模块/人/时间筛选

## 2. 非功能落地（NFR-01~08）

| 编号 | 需求 | 落地设计 |
|------|------|----------|
| NFR-01 | 集中化 | 单一系统单一数据库；禁止引入外部表格作为事实源（XLSX 仅导入导出媒介） |
| NFR-02 | 多店铺多供应商 | Shop / Supplier 均为一等实体；所有列表默认带店铺筛选 |
| NFR-03 | 易用 | 财务主链路 ≤3 步出结果；全局 Ctrl+K 编码搜索；未匹配支持按文本批量指定 |
| NFR-04 | 提醒任务 | Reminder 表 + 定时任务；8 天周期；站内推送；失败重试 3 次入日志（详见 08 文档） |
| NFR-05 | 数据导入 | 成本表固定模板 XLSX，表头校验，行级异常跳过并出清单；订单 CSV 关键列识别，缺列阻断（详见 04/06 文档） |
| NFR-06 | 数据安全 | 独立账号 + 密码策略；菜单裁剪 + 接口鉴权双层；成本/利润字段接口级过滤（未授权 403）；手机号等 PII 脱敏展示。**详细设计见《安全设计文档》** |
| NFR-07 | 性能 | CSV 解析与匹配走异步批次任务；倒排索引批量内存匹配；1 万行 ≤30s |
| NFR-08 | 可追溯 | 批次不可变 + 版本化重算；CostPrice 历史表；OrderLine 存价格快照；操作日志 |

## 3. 部署与数据（建议项）

- 数据库备份交给部署环境（每日全备 +binlog），系统内不实现备份 UI（Q8 默认口径）
- 文件存储：发票附件、产品图片、OCR 原图走对象存储或本地可配置目录
- 定时任务：发票提醒扫描、日报生成；由 Celery Beat 承担；备份用 Windows 任务计划程序（schtasks）

## 4. MVP 范围（与总览文档一致）

**做**：账号权限、供应商+规格成本表+编码生成、XLSX 导入、店铺产品登记、订单上传→计算→未匹配闭环→重算、附加规则配置、工作台待办、日报页面版。

**缓（二期）**：小程序端（uni-app/Taro 复用 API）、报价 OCR、ROI 对接投放平台、微信/短信推送、趋势图表增强、待结算订单表双表核对。

**不做（首版）**：移动端、多仓/多物流商对接、自动拉取抖店后台。
