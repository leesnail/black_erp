## 已闭环决策速查

| 决策 | 结论 |
|------|------|
| 关联主键 | 规格编码（方案 A），标题+售价仅作订单侧反查 |
| 地区附加 | 按件计：青海/海南/内蒙/宁夏/甘肃 +4，新疆/西藏 +20 |
| 售后口径 | 退货仍计成本；售后单数仅展示 |
| 商家实收 | Σ商家收入金额，系统自动算 |
| 成本表导入 | 固定模板 XLSX，表头校验，不做列映射 |
| 一单多品 | 逐行匹配、逐行归集成本 |
