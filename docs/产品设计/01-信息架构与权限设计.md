# 01 信息架构与权限设计

> 对应需求：FR-Auth-01~04、角色权限表

## 1. 菜单结构（按角色裁剪）

```
工作台（待办/提醒/快捷入口）          ← 全员
├── 客服工作台                        ← 客服
│   ├── 售后登记
│   ├── 供应商对接
│   └── 发票管理（登记/回传/提醒）
├── 成本报价（采购模块）               ← 采购（写）｜运营/财务/老板（读）
│   ├── 供应商管理
│   ├── 报价录入（含 OCR）
│   ├── 规格成本表（主数据）
│   └── XLSX 模板导入
├── 运营管理                          ← 运营
│   ├── 店铺产品登记
│   └── ROI 计算
├── 财务核算                          ← 财务（写）｜老板（读）
│   ├── 订单上传与计算
│   ├── 计算批次列表
│   ├── 未匹配处理
│   ├── 成本明细 / 月度对账
│   └── 经营日报
├── 经营驾驶舱                        ← 老板/管理员
│   ├── 利润总览（多店铺）
│   ├── 日报中心
│   └── 趋势分析
└── 系统管理                          ← 管理员
    ├── 账号管理
    ├── 角色与权限
    ├── 附加成本规则（省份+金额）
    └── 操作日志
```

## 2. 角色-页面矩阵

| 页面 | 老板 | 管理员 | 客服 | 采购 | 运营 | 财务 |
|------|:----:|:------:|:----:|:----:|:----:|:----:|
| 工作台 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| 售后/发票 | – | ✓ | **写** | – | – | – |
| 供应商管理 | ✓ | ✓ | 写 | **写** | 读 | – |
| 规格成本表 | 读 | ✓ | – | **写** | 读 | 读 |
| 报价录入/OCR | – | ✓ | – | **写** | – | – |
| XLSX 导入 | – | ✓ | – | **写** | – | – |
| 店铺产品登记 | 读 | ✓ | – | – | **写** | – |
| ROI 计算 | – | ✓ | – | – | **写** | – |
| 订单上传与计算 | 读 | ✓ | – | – | – | **写** |
| 未匹配处理 | – | ✓ | – | – | – | **写** |
| 成本明细/对账 | 读 | ✓ | – | – | 读 | **读/导出** |
| 经营日报/驾驶舱 | **读** | ✓ | – | – | – | 读 |
| 系统管理 | – | **写** | – | – | – | – |

> ✓ = 全部操作；读 = 只读（可导出）；– = 菜单不可见。

## 3. 权限规则落地

| 编号 | 规则 | 技术落地 |
|------|------|----------|
| FR-Auth-01 | 独立账号登录 | 账号-角色-模块权限三张表；密码策略（长度/复杂度/定期更换） |
| FR-Auth-02 | 管理员可分配模块可见范围 | 权限配置页按"角色默认 + 个人覆盖"两层；覆盖项高亮显示 |
| FR-Auth-03 | 无权限不可见 + 接口拒绝 | 前端按权限渲染菜单（非 CSS 隐藏）；后端中间件按模块鉴权，未授权返回 403 |
| FR-Auth-04 | 只读 = 查/导出，无增删改 | 数据接口按 action 粒度鉴权（list/detail/export 允许；create/update/delete 拒绝） |

## 4. 全局导航要素

- **顶栏**：消息中心、当前账号
- **工作台待办卡**：发票提醒（8 天周期）、未匹配订单数、报价待补录、日报未读
- **全局编码搜索**：任何页面 Ctrl+K 按规格编码/产品名直达成本表详情
