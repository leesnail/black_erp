# 08 工作台与驾驶舱设计

> 对应需求：FR-FIN-04 日报、NFR-04 提醒任务、老板全局查看
> 使用角色：全员（工作台）｜老板/管理员（驾驶舱）

## 1. 工作台

```
┌──────────────────────────────────────────────────────┐
│ 待办                    快捷入口                       │
│ ┌────────┐ ┌────────┐ ┌────────┐   [上传订单] [报价录入] │
│ │发票提醒 │ │未匹配   │ │报价待补│   [店铺登记] [看日报]   │
│ │ 3 条   │ │ 12 单  │ │ 2 项   │                      │
│ └────────┘ └────────┘ └────────┘                      │
│ 最近批次：誉恒 2026-08 · 成本 ¥12,345 · 利润 ¥6,789 →   │
└──────────────────────────────────────────────────────┘
```

- 待办卡**按角色显示**：
  - 客服 → 发票提醒（未回传发票数）
  - 财务 → 未匹配订单数、最近批次异常
  - 采购 → 报价待补录（超 N 天未更新的启用规格，N 默认 30，可配）
  - 运营 → 无专属卡，显示登记变更提示
  - 老板 → 汇总卡（昨日利润/本月利润/未匹配积压）
- 卡片点击直达对应处理页
- 消息中心（顶栏铃铛）：所有 Reminder 的列表，支持全部已读

## 2. 发票提醒链路（NFR-04）

```
定时任务（每日扫描）
  → 找出登记满 8 天仍未回传的发票
  → 写 Reminder（待触发）→ 触发站内消息 + 待办卡 + 角标
  → 失败重试 3 次 → 仍失败写失败日志（系统管理-操作日志可见）
```

- 已读 ≠ 已处理：未回传的下一轮仍提醒
- 管理员可查看提醒历史与失败记录

## 3. 经营日报（FR-FIN-04）

**生成**：每日 09:00 定时任务，按店铺汇总前一日（自然日）数据。

**日报内容（页面版，日报中心）**

| 店铺 | 订单量 | 售后单 | 实收 | 成本 | 利润 | 环比 |
|---|---|---|---|---|---|---|
| 誉恒 | 86 | 3 | ¥8,120 | ¥3,700 | ¥4,420 | +5.2% |

- 数据源：已完成计算批次中该日的 OrderLine；无批次则显示"当日未核算"提示
- 环比：与前一日对比
- 导出 XLSX
- 推送渠道：首版站内（工作台老板卡 + 消息中心）；微信/短信二期（对应 Q3 遗留）

## 4. 经营驾驶舱（老板/管理员）

```
┌ 经营驾驶舱  期间[2026-08▾]
│ 卡片: 总实收 ¥328,900 | 总成本 ¥151,200 | 总利润 ¥177,700 | 利润率 54%
│ 图表: 店铺利润对比柱状图 · 近 6 月利润趋势折线
│ 表格: 各店铺汇总（同财务汇总，全店铺） · 未匹配积压提示
└
```

- 期间切换：日/月
- 图表库建议 ECharts；数据量小直接后端聚合返回
- 未匹配积压 > 0 时置顶黄条提醒财务处理
